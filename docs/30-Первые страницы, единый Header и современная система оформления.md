# День 30. Первые страницы, единый Header и современная система оформления

## Задача дня

Начать наполнять основные разделы новой версии сайта реальными страницами и сделать так, чтобы посетитель мог открыть их прямо из горизонтального меню.

Одновременно нужно было устранить визуальные расхождения Header на обычных страницах, в разделе «Новости и медиа», в полном списке новостей и на странице отдельной публикации.

Финальная цель дня — получить не набор похожих, но независимых страниц, а одну понятную систему:

```text
одно горизонтальное меню
        ↓
реальные страницы RU / HU
        ↓
единые Header, стили и правила оформления
```

---

## Просто о сложном

Страница сайта состоит не только из текста, который видит посетитель. Обычно она собирается из нескольких частей:

- общий Header — верхняя часть сайта и главное меню;
- содержимое конкретной страницы;
- CSS — правила внешнего вида;
- общий Footer — нижняя часть сайта.

Если одна страница подключает актуальный Header, а другая — старую копию, внешне это выглядит так, будто открылись два разных сайта. Если HTML-разметка новая, а CSS остался старым, элементы тоже теряют правильные размеры и расположение.

Поэтому главная работа дня заключалась не в том, чтобы отдельно «подкрасить» каждую страницу, а в том, чтобы вернуть всем страницам общие компоненты и одинаковые правила.

---

## Что сделали

### 1. Первые реальные страницы подключили к горизонтальному меню

Раньше часть пунктов меню была временной. Ссылка могла содержать `#` или вести на страницу-заглушку. Такой пункт выглядел готовым, но не открывал полноценный раздел.

Рабочие адреса были вынесены в общий файл:

```text
/new-home/includes/header.php
```

В нём для каждого готового раздела задаётся свой адрес. Например:

```php
$aboutUrl = $isHu
    ? '/new-home/hu/the-russian-culture-centre-in-budapest.php'
    : '/new-home/the-russian-culture-centre-in-budapest.php';

$newsUrl = $isHu
    ? '/new-home/hu/media/'
    : '/new-home/ru/media/';

$educationUrl = $isHu
    ? '/new-home/hu/education-in-russia.php'
    : '/new-home/education-in-russia.php';
```

Простыми словами: Header сначала определяет язык страницы, а затем сам подставляет нужный русский или венгерский адрес.

Первыми полноценными пунктами горизонтального меню стали:

- «О центре» / `A központról`;
- «Новости и анонсы» / `Hírek és programok`;
- «Обучение в России» / `Tanulás Oroszországban`.

Для посетителя это обычный клик по меню. Для проекта это важное изменение: одна и та же структура Header обслуживает обе языковые версии, поэтому не нужно вручную исправлять две независимые копии меню.

---

### 2. Оформили страницы «О центре» на русском и венгерском

Страница о Российском культурном центре получила полноценные русскую и венгерскую версии.

На странице:

- сохранена общая структура нового сайта;
- добавлена активная ссылка на официальный сайт Центра;
- изображению задано понятное альтернативное описание;
- подпись под фотографией оформлена аккуратно и выровнена по центру;
- ссылка возврата перенесена в привычное место над содержимым;
- правая информационная колонка приведена к тому же принципу, который используется на страницах новостей.

Отдельно была устранена ошибка 404 у изображения. Причина оказалась простой: адрес картинки в коде должен полностью совпадать с настоящим именем файла на сервере — включая все символы, расширение и каталог.

### 3. Создали страницы «Обучение в России» на двух языках

Подготовлены две отдельные точки входа для посетителей:

```text
/new-home/education-in-russia.php
/new-home/hu/education-in-russia.php
```

Страницы получили:

- русский и венгерский тексты;
- актуальную структуру разделов;
- активные переходы на официальные информационные ресурсы;
- единый Header и Footer;
- компактный синий заголовок с белым текстом;
- ссылку «Вернуться на главную» над заголовком;
- боковой блок действий по образцу страницы публикации;
- адаптивное отображение на узких экранах.

Главное для человека, который никогда не работал с CMS: сама страница уже является готовым PHP-файлом. После загрузки в нужный каталог она начинает работать, а ссылка на неё задаётся один раз в общем Header.

---

### 4. Исправили расхождение между разметкой Header и его стилями

Во время обновления обнаружилась неприятная, но типичная ошибка: на части страниц использовалась неполная или устаревшая версия Header, а файл стилей ожидал другую HTML-разметку.

Из-за этого верхняя часть сайта могла выглядеть увеличенной, разъехавшейся или непривычно пустой. Проблема была не в содержимом страницы, а в несовпадении двух частей одного компонента:

```text
разметка Header ≠ CSS Header
```

Исправление было системным:

1. восстановлен актуальный общий `header.php`;
2. подключён соответствующий ему `header.css`;
3. ссылки на стили сделаны абсолютными — от `/new-home/`;
4. к адресу CSS добавлена версия, чтобы браузер не показывал старый файл из кеша;
5. маршруты первых готовых страниц изменены только в одном общем месте.

После этого Header снова стал одинаковым на главной, на обычных информационных страницах и в новостных разделах.

---

### 5. Привели к общему виду все уровни раздела новостей

У раздела новостей есть несколько разных экранов:

```text
«Новости и медиа»
        ↓
«Все новости»
        ↓
отдельная открытая публикация
```

В браузере их адреса выглядят по-разному, но они должны использовать один и тот же Header. Ранее на отдельных уровнях появлялась старая верхняя часть сайта.

Были проверены и согласованы подключения общего Header и его CSS для:

- обзорной страницы «Новости и медиа»;
- страницы «Все новости»;
- страницы полной новости;
- русской и венгерской маршрутизации.

Важный технический момент объясняется просто: красивый адрес новости может выглядеть как вложенная папка, но `.htaccess` передаёт его общему PHP-шаблону. Поэтому шаблон должен подключать общий Header из фактического каталога проекта, а стили должны иметь абсолютные адреса.

Итог: переход между обзором, списком и полной публикацией больше не меняет внешний вид верхней части сайта.

---

### 6. Навели порядок в стилях

Проблема была не в недостатке CSS, а в том, что несколько правил могли одновременно пытаться оформить один и тот же элемент.

Были разделены зоны ответственности:

- `header.css` отвечает за Header;
- `page-template.css` — за обычные информационные страницы;
- `repository.css` — за каталоги и списки публикаций;
- `news.css` — за полную страницу новости;
- `footer.css` — за Footer;
- локальные правила страницы используются только там, где действительно требуется особое оформление.

Для страницы «Обучение в России» размеры были синхронизированы со страницей «Новости и медиа»:

- одинаковая ширина основного контейнера;
- одинаковый верхний отступ;
- одинаковое положение ссылки возврата;
- одинаковые размер шрифта и внутренние поля синего заголовка;
- одинаковая логика мобильной версии.

Также был устранён эффект «двойного оформления», когда фон и внутренние поля применялись одновременно к внешнему контейнеру и к самому заголовку. Теперь синий фон занимает ровно ту область, которая нужна тексту.

Версии в адресах CSS позволяют после обновления получать новый дизайн сразу:

```html
<link rel="stylesheet" href="/new-home/css/header.css?v=20260909-1">
```

Часть после `?v=` не создаёт новый файл. Она сообщает браузеру, что нужно заново загрузить уже существующий CSS.

### 7. Выбрали современный дизайн без отказа от корпоративного стиля

Современный дизайн не обязательно означает полную смену визуального характера организации.

За основу сохранены узнаваемые элементы Центра:

- фирменный синий цвет;
- белый фон и спокойная нейтральная палитра;
- официальный логотип;
- строгая горизонтальная навигация;
- ясная информационная иерархия.

Современность добавлена за счёт других решений:

- компактные цветовые плашки заголовков вместо тяжёлых декоративных блоков;
- больше свободного пространства между смысловыми частями;
- модульные карточки и боковые панели;
- тонкие границы и умерленные скругления;
- адаптивный размер текста через `clamp()`;
- заметные, но не кричащие состояния ссылок;
- единый ритм отступов на разных страницах.

Получился не «чужой модный шаблон», а обновлённая цифровая версия существующего образа Центра: официальная, спокойная и узнаваемая, но более лёгкая и удобная для чтения.

## Как повторить такой переход с нуля

Если объяснять последовательность человеку без опыта работы с CMS, она выглядит так:

1. Сначала полностью подготовить новую страницу и проверить её прямой адрес.
2. Загрузить PHP-файл в правильный каталог на сервере.
3. Открыть общий файл `/new-home/includes/header.php`.
4. Найти переменную нужного пункта меню и заменить временный адрес на рабочий.
5. Не копировать Header внутрь каждой страницы, а подключать общий компонент.
6. Проверить, что CSS подключается от абсолютного пути `/new-home/css/...`.
7. После изменения CSS обновить номер после `?v=`.
8. Открыть главную, раздел «Новости и медиа», «Все новости» и отдельную публикацию.
9. Проверить русскую и венгерскую версии.
10. Выполнить принудительное обновление браузера через `Ctrl + F5`.

Эта последовательность помогает отличить три разные причины проблемы:

```text
неверная ссылка → не открывается страница
неверное подключение → появляется не тот Header
старый CSS в кеше → код исправлен, но внешний вид ещё прежний
```
