```text

```

## 2. Создание таблицы истории изменений

Создана отдельная таблица

```text
content_revisions
```

которая предназначена для хранения истории изменений публикаций.

Структура предусматривает хранение:

- типа сущности;
- идентификатора записи;
- операции;
- предыдущего состояния;
- нового состояния;
- автора изменения;
- времени изменения.

Архитектура:

```text
Редактирование
        ↓
content_revisions
        ↓
История изменений
```

## 4. Подготовка SQL-запроса к новой архитектуре

Запрос выборки публикаций был обновлён.

- slug;

## 5. Подготовка первой системы slug

Для первой публикации заполнено поле

```text
slug
```

например:

```text
nastoyaschiy-russkiy-duh
```

Получена новая схема идентификации публикаций.

Вместо:

```text
?id=15
```

используется:

```text
slug
```

Архитектура:

```text
Карточка
        ↓
slug
        ↓
Уникальная публикация
```
