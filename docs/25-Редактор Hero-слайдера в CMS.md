# Что было сделано — простыми словами

В День 25 главный экран сайта перестал быть статическим блоком, который можно изменить только вручную в коде.

Для уже работающего Hero-слайдера разработан собственный редактор в CMS. Теперь администратор может создавать и редактировать слайды, выбирать изображения из медиатеки, задавать заголовок, короткое пояснение и ссылку, менять порядок показа и временно отключать отдельные слайды.

Главное новшество — два самостоятельных режима изображения:

- **с затемнением** — для слайда с крупным белым заголовком и поясняющим текстом;
- **без затемнения** — для афиш, плакатов и других изображений, которые должны показываться в исходной яркости.

При этом уже работающие кнопки перелистывания и индикаторы слайдов сохранены.

---

# Главная задача дня

Подключить Hero-слайдер главной страницы к собственной CMS так, чтобы его можно было обновлять без редактирования PHP, HTML, CSS и JavaScript вручную.

Итоговая цепочка стала такой:

```text
редактор CMS
        ↓
проверка и сохранение данных
        ↓
таблица hero_slides
        ↓
публичный PHP-компонент
        ↓
Hero-слайдер на главной странице
```

---

# 1. Отдельное хранилище для слайдов

Для Hero-слайдера подготовлена собственная таблица базы данных.

Она хранит:

- заголовок;
- мини-лид;
- текст кнопки;
- адрес перехода;
- путь к изображению;
- альтернативное описание изображения;
- режим отображения;
- порядок слайда;
- статус активности;
- даты создания и обновления.

Слайды не смешиваются с новостями, анонсами и международными событиями. Это делает назначение данных понятным и упрощает дальнейшее обслуживание.

---

# 2. Редактор Hero-слайдера в CMS

В административной части появился отдельный экран управления слайдами.

Редактор позволяет:

1. создать новый слайд;
2. изменить существующий;
3. выбрать изображение;
4. заполнить заголовок и мини-лид;
5. указать подпись и URL кнопки;
6. включить или отключить затемнение;
7. задать порядок показа;
8. включить или выключить публикацию;
9. удалить ненужный слайд.

Пользователю CMS не требуется работать с кодом: основные настройки собраны в понятной форме.

---

# 3. Повторное использование медиатеки

Hero-редактор подключён к ранее созданной медиатеке.

Это означает, что изображение можно:

- выбрать из уже загруженных файлов;
- не загружать повторно;
- использовать с сохранённым путём;
- снабдить корректным `alt`-описанием.

Так медиатека стала общим источником изображений не только для публикаций, но и для главного визуального блока сайта.

---

# 4. Два режима показа изображения

## Слайд с затемнением

Этот режим предназначен для текстового Hero-слайда.

Поверх фотографии выводятся:

- большой заголовок;
- мини-лид;
- кнопка перехода;
- элементы навигации.

Затемнение повышает контраст и сохраняет читаемость белого текста.

## Слайд без затемнения

Этот режим нужен для изображений, которые важно показать без визуального фильтра:

- афиш;
- информационных плакатов;
- фирменной графики;
- изображений, где цвет является частью содержания.

CMS сохраняет выбранный режим для каждого слайда отдельно.

# 5. Публичный PHP-компонент

Вывод Hero-слайдера вынесен в отдельный компонент:

```text
/new-home/includes/hero-slider.php
```

Компонент:

- получает только активные записи;
- соблюдает заданный порядок;
- безопасно выводит текстовые значения;
- формирует необходимую HTML-разметку;
- добавляет режим затемнения отдельным классом;
- сохраняет совместимость с существующей навигацией.

Главная страница подключает компонент вместо прежнего статического Hero-блока.
