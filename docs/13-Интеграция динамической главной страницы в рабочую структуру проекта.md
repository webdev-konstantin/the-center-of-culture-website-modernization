```text

│

│

├── news.php
├── favicon.ico

└── .htpasswd
```

Рабочая версия сайта более не зависит от резервной директории.

## 2. Настройка защиты проекта

Полностью восстановлена защита тестовой версии сайта.

Использованы файлы:

```text
.htaccess
.htpasswd
```

Основная конфигурация:

```apache
AuthType Basic
AuthName "Restricted Area"

AuthUserFile
/home/.../docs/new-home/.htpasswd

```

Дополнительно сохранён запрет индексации.

```apache

"noindex, nofollow, noarchive, nosnippet, noimageindex"
```
