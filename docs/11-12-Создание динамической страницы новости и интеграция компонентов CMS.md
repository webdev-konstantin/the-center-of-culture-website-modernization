# Цель

Преобразовать статический шаблон новости в полноценную динамическую страницу, работающую через собственную CMS, сохранив современный внешний вид нового сайта.

Основной задачей являлось создание универсального шаблона публикации, который автоматически получает данные из базы MySQL и использует единые компоненты оформления всего сайта.

Планируемая архитектура:

```text
Browser
        ↓
news.php
        ↓
MySQL
        ↓
home_feed_items
        ↓
Динамическая статья
        ↓
Компонент "Последние новости"
```

# Выполненные работы

## 1. Подключение динамической загрузки новости

Страница была полностью подключена к базе данных CMS.

Реализовано:

- загрузка статьи по `slug`;
- использование Prepared Statements;
- проверка опубликованных материалов;
- загрузка изображения;
- подключение тегов публикации;
- автоматическая выдача страницы 404 при отсутствии статьи.

### Основные файлы проекта

```text
/docs/news.php
/docs/includes/latest-news.php
/docs/includes/db.php
```

### Основные переменные

```php
$slug
$title
$seoTitle
$seoDescription
$imagePath
$visibleDate
$fullText
$tags
```

### Используемая таблица базы данных

```text
home_feed_items
```

### Основные поля

```text
id
title
slug
subtitle
full_text
image_path
publication_date
tags
seo_title
seo_description
locale
published
```

### Основной SQL-запрос

```sql
SELECT
    id,
    title,
    slug,
    subtitle,
    full_text,
    image_path,
    publication_date,
    tags,
    seo_title,
    seo_description
FROM home_feed_items
WHERE slug = ?
AND locale = 'ru'
AND published = 1
LIMIT 1;
```

### Схема работы

```text
URL
        ↓
slug
        ↓
Prepared Statement
        ↓
MySQL
        ↓
fetch_assoc()
        ↓
PHP-переменные
        ↓
Шаблон страницы
```
