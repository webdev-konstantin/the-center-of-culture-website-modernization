# Что было сделано — простыми словами

День 17 превратил ограниченные ленты главной страницы в полноценную систему хранения, навигации и поиска по публикациям.

До этого новости и анонсы уже загружались из таблицы `home_feed_items`, но посетитель в основном взаимодействовал с несколькими карточками каруселей. Старые материалы сохранялись в базе, однако отдельного удобного интерфейса для просмотра всех публикаций ещё не существовало.

В течение дня были созданы:

```text
общая страница «Новости и медиа»
        ↓
полный репозиторий новостей
        ↓
объединённый репозиторий анонсов и международных событий
        ↓
поиск, фильтрация, пагинация и календарь
```

На главной появились два перехода:

```text
Все новости и медиа →
Все анонсы и события →
```

Настроены красивые URL:

```text
/new-home/ru/media/
/new-home/ru/news/
/new-home/ru/events/
```

Для анонсов и международных событий разработан двухмесячный календарь с выбором диапазона, быстрыми периодами, кнопками применения и сброса, а также синхронизацией с серверной MySQL-фильтрацией.

# 1. Архитектура репозиториев

Сохранены три редакционных типа:

```text
news          → новости
event         → анонсы РКЦ
international → международные события
```

Публично активированы две коллекции:


Отдельная коллекция `international` описана в конфигурации, но пока отключена как самостоятельная страница.

## Принцип «витрина и полный каталог»

Главная остаётся витриной:

```text

→ несколько актуальных карточек
```

Репозиторий показывает полный поток:

```text
все опубликованные материалы
→ поиск
→ фильтры
→ пагинация
```

Материал, вытесненный из карусели новой записью, не исчезает: он остаётся доступным в репозитории.

# 3. Создание `repository-query.php`

```text

```

Он отвечает за:

- пагинацию;

Для событий дата вычисляется так:



# 10. Красивые URL

В `.htaccess` добавлены маршруты:

```apache
RewriteRule ^(ru|hu)/media/?$ \
    media.php?locale=$1 [L,QSA,NC]

RewriteRule ^(ru|hu)/news/?$ \
    repository.php?collection=news&locale=$1 [L,QSA,NC]

RewriteRule ^(ru|hu)/events/?$ \
    repository.php?collection=events&locale=$1 [L,QSA,NC]

RewriteRule ^(ru|hu)/news/([a-z0-9-]+)/?$ \
    news.php?locale=$1&slug=$2 [L,QSA,NC]
```

Правило репозитория `/ru/news/` размещено перед правилом подробной публикации `/ru/news/<slug>`, поэтому Apache корректно различает список и отдельный материал.

Технические адреса сохраняют совместимость, но публичная навигация использует красивые маршруты.

# 12. `repository-calendar.js`

Создан файл:

```text
/docs/new-home/js/repository-calendar.js
```

Скрипт:

- строит два месяца;
- выводит дни недели;
- создаёт 42 ячейки на месяц;
- отмечает текущую дату;
- выбирает начало и конец диапазона;
- подсвечивает промежуточные дни;
- переключает месяцы;
- заполняет `date_from` и `date_to`;
- восстанавливает состояние из URL.

```javascript
function handleDateSelection(clickedDate) {
    if (!selectedStart || selectedEnd) {
        selectedStart = clickedDate;
        selectedEnd = null;
    } else if (
        compareDates(clickedDate, selectedStart) < 0
    ) {
        selectedStart = clickedDate;
        selectedEnd = null;
    } else {
        selectedEnd = clickedDate;
    }

    renderCalendar();
}
```

JavaScript не обращается к базе напрямую:

```text
календарь
→ поля GET
→ repository-query.php
→ подготовленный SQL
→ отфильтрованные карточки
```
