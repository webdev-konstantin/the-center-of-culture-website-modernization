# 1. Конфигурация репозиториев

Три редакционных типа материалов обслуживаются двумя публичными репозиториями.

```php
$collections = [
    'news' => [
        'enabled' => true,
        'content_types' => ['news'],
        'route' => 'news',
        'date_field' => 'publication_date',
        'sort_mode' => 'newest_first'
    ],

    'events' => [
        'enabled' => true,
        'content_types' => [
            'event',
            'international'
        ],
        'route' => 'events',
        'date_field' => 'event_start',
        'fallback_date_field' =>
            'publication_date',
        'sort_mode' =>
            'upcoming_then_recent',
        'show_type_filter' => true
    ],

    'international' => [
        'enabled' => false,
        'content_types' => [
            'international'
        ]
    ]
];
```

Это позволяет позднее включить отдельный репозиторий международных событий без миграции данных.

# 2. Универсальная дата для фильтрации

Новости фильтруются по дате публикации, а события — по `event_start` с резервным переходом на `publication_date`.

```php
$dateExpression =
    $collectionKey === 'events'
        ? 'COALESCE(
            event_start,
            publication_date
        )'
        : 'publication_date';
```

```text
news
→ publication_date

event / international
→ event_start
→ publication_date, если event_start отсутствует
```

# 4. Пагинация

Сначала выполняется отдельный `COUNT`, затем рассчитывается смещение.

```php
$totalPages = max(
    1,
    (int) ceil(
        $totalItems /
        $itemsPerPage
    )
);

$offset =
    ($currentPage - 1) *
    $itemsPerPage;
```

Основной запрос получает только записи текущей страницы:

```sql
LIMIT ? OFFSET ?
```

# 6. Красивые URL

```apache
RewriteRule ^(ru|hu)/media/?$ \
    media.php?locale=$1 \
    [L,QSA,NC]

RewriteRule ^(ru|hu)/news/?$ \
    repository.php?collection=news&locale=$1 \
    [L,QSA,NC]

RewriteRule ^(ru|hu)/events/?$ \
    repository.php?collection=events&locale=$1 \
    [L,QSA,NC]

RewriteRule ^(ru|hu)/news/([a-z0-9-]+)/?$ \
    news.php?locale=$1&slug=$2 \
    [L,QSA,NC]
```

Порядок правил отличает полный репозиторий `/news/` от отдельной публикации `/news/<slug>`.

# 7. Выбор диапазона в календаре

```javascript
function handleDateSelection(
    clickedDate
) {
    if (
        !selectedStart ||
        selectedEnd
    ) {
        selectedStart = clickedDate;
        selectedEnd = null;
    } else if (
        compareDates(
            clickedDate,
            selectedStart
        ) < 0
    ) {
        selectedStart = clickedDate;
        selectedEnd = null;
    } else {
        selectedEnd = clickedDate;
    }

    displayMonth =
        firstDayOfMonth(
            selectedStart ||
            clickedDate
        );

    renderCalendar();
}
```

Первый клик начинает диапазон, второй завершает его. Новый клик после завершённого диапазона начинает новый выбор.

# 8. Синхронизация с серверной формой

```javascript
const updateInputs = () => {
    inputFrom.value =
        selectedStart
            ? formatIsoDate(
                selectedStart
            )
            : '';

    inputTo.value =
        selectedEnd
            ? formatIsoDate(
                selectedEnd
            )
            : '';
};
```

JavaScript не заменяет серверную фильтрацию. Он только записывает даты в поля формы, после чего PHP и MySQL выполняют обычный GET-запрос.

# 9. Progressive enhancement

```javascript
form.classList.add(
    'has-enhanced-calendar'
);
```

```css
.repository-filter-form.has-enhanced-calendar
.repository-date-row--calendar-sync {
    display: none;
}
```

```text
JavaScript загрузился
→ показывается интерактивный календарь
→ техническая строка дат скрывается

JavaScript не загрузился
→ обычные поля date_from и date_to остаются доступны
```

Это сохраняет работоспособность серверного фильтра даже при проблемах с JavaScript.
