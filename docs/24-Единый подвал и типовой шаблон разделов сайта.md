# Что было сделано — простыми словами

В День 24 сайт получил две важные общие конструкции: единый подвал и типовой шаблон внутренних разделов.

Раньше футер приходилось подключать и проверять на разных страницах отдельно, а новые информационные разделы не имели единого каркаса. Теперь общие элементы вынесены в повторно используемые PHP- и CSS-файлы.

Итоговая схема стала понятной:

```text
общий header
        ↓
содержимое конкретной страницы
        ↓

```

Одновременно был подготовлен шаблон, на основе которого можно создавать страницы «О центре», «Обучение в России», «Изучение русского языка», «Проекты и программы» и другие разделы главного меню.

# 4. Подключение футера к публичным страницам


Стандартное подключение выглядит так:

```php
<?php

?>
```

Оно располагается после закрытия основного содержимого и до закрывающих тегов `body` и `html`.

# 5. Диагностика страницы «Новости и медиа»

На маршруте:

```text
/new-home/ru/media/
```

страница открывалась, но футер не появлялся.

Причина оказалась не в самом `footer.php`, а в окончании `media.php`: там оставались повторные закрывающие теги и неверное положение подключения.

Правильная структура конца файла:

```php
</main>

<?php
require_once __DIR__ . '/includes/footer.php';
?>

</body>
</html>
```

После удаления дубликатов футер начал выводиться корректно.

# 6. Контроль размеров логотипа

При первом подключении логотип оказался значительно больше области футера. Причина была в том, что изображение не получило ограничений внутри нового контекста страницы.

Размер был зафиксирован средствами CSS:

```css
.site-footer__logo-image {
    display: block;
    width: 100%;
    max-width: 150px;
    height: auto;
}
```

Теперь логотип сохраняет пропорции, не выходит за пределы своей колонки и адаптируется к ширине экрана.

# 7. Типовой шаблон внутренних страниц

Создан универсальный PHP-шаблон для разделов главного меню.

Настройки конкретной страницы задаются в начале файла:

```php
$pageTitle = 'Центр ДПО';
$pageDescription = '...';
$pageEyebrow = 'О ЦЕНТРЕ';
$pageLead = '...';
$currentLocale = 'ru';
$pageImage = '/new-home/img/example.jpg';
$pageImageAlt = 'Описание изображения';
$pageImageCaption = 'Подпись под изображением';
```

Остальная архитектура остаётся общей.

Это означает, что новая страница создаётся не копированием случайных фрагментов, а заполнением нескольких понятных параметров.

# 10. Главное изображение, alt и подпись

В шаблон встроен полноценный семантический блок `figure`:

```html
<figure class="standard-page__figure">
    <img
        class="standard-page__image"
        src="..."
        alt="..."
    >
    <figcaption class="standard-page__caption">
        ...
    </figcaption>
</figure>
```

Это обеспечивает:

- корректное масштабирование изображения;
- доступное текстовое описание;
- редакционную подпись;
- единый размер с главным изображением публикации;
- аккуратное отображение рядом с боковой колонкой.
